💡 Почему Flex?

Сравним с Python. Одинаковая задача — разный опыт.

🐍 Python

def greet(name):
    if age >= 18:
        print(f"Hello, {name}!")
    else:
        print("Too young")

⚡ Flex

define greet(name):
{
    if age is greater than 18:
    {
        say "Hello, {name}!"
    }
    otherwise:
    {
        say "Too young"
    }
}
🗣

Читается как книга

if age is greater than 18 — не нужно помнить, что значит >=.

🧹

Меньше шума

Нет def, lambda, None. Только нужные слова.

🛡

Прощает ошибки

Понятные сообщения: "Ты забыл скобки после if".
